# Changelog

## [v1.1.0] - 2026-09-29

### Fixed
- **Комиссия теперь вычитается из баланса, а не из суммы отправки**
  - Раньше: указываешь 0.001 BTC → получатель получал 0.001 минус комиссия
  - Теперь: указываешь 0.001 BTC → получатель получит ровно 0.001 BTC, комиссия списывается с твоего баланса
  - MAX режим: отправляет весь баланс минус комиссия (как и было)

- **Offline mode (RAW HEX) теперь полностью изолирован от broadcast**
  - TX строится локально, никогда не транслируется
  - Подходит для отправки через mining pool в обход мемпула (защита от фронтраннинга)
  - Скопировать HEX → mempool.space/tx/push или прямо в пул

### Improved
- **Адаптивный UI для разных разрешений**
  - Убран фиксированный размер окна → можно растягивать по вертикали
  - Шрифты уменьшены (11px → 9-10px) для компактности
  - Отступы и padding оптимизированы для малых экранов
  - Verification card теперь растягивается по контенту

- **Улучшенный диалог подтверждения**
  - Показывает точную сумму, которую получит адресат
  - Показывает сколько спишется с баланса (сумма + комиссия)
  - Явное предупреждение: "Транзакция будет немедленно отправлена в сеть"

- **Более точный preview комиссии**
  - Показывает "Получит адресат" вместо "К отправке"
  - В MAX режиме корректно показывает баланс минус комиссия
  - Валидация: если баланс недостаточен для (amount + fee) — показывает ошибку

### Technical
- Создан `requirements.txt` с pinned версиями
- CSS переписан на system font stack (-apple-system, Segoe UI) для нативного вида
- Размеры кнопок и полей уменьшены для лучшей плотности
- Monospace font stack: 'Courier New', 'Consolas', monospace
